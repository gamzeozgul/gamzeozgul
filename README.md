## Featured Project

### [Willow & Comb](https://github.com/gamzeozgul/willow-and-comb) - booking system for a fictional salon
One-page booking site on Google Apps Script, a Google Sheet as the owner's back office, and n8n for salon notifications, next-day reminders and review requests.

- Lock + re-check so two people cannot take the same slot
- Time-zone and daylight-saving correct (America/Chicago)
- Every mail stamped on the row, so nothing is sent twice
- Error workflow mails the owner when a scheduled run fails
- 39 automated tests, including the n8n Code nodes

**Tech:** JavaScript, Google Apps Script, Google Sheets, n8n, Gmail
